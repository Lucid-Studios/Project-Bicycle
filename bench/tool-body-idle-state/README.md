# Tool Body Idle State Bench

This bench records the first cold lane where Project Bicycle holds the
Sanctuary tool body in an idle state that is not maintained by an LLM.

The lane proves only that the installed organs, membranes, EC residue, warm-use
lineage, lab GEL substrate, pre-admission engram closure, and lab readback can
stand as an inspectable idle posture. It marks governance SLM / micro-LM support
as a future intelligent routing-switch candidate that may help discern action
readiness, but that discernment is not action authority. It does not bind a
model, call a provider, run a tick loop, grant authority, authorize action, admit
GEL, mutate SelfGEL, activate heartbeat, or admit CME.Actual / Sanctuary.Actual.

