# LLM Tick Cycle Bench

This bench records the v0.9.1 cold tick harness.

The lane proves that Project Bicycle can seat a deterministic model adapter, require a pre-admission engram closure payload, witness one bounded adapter response per tick, route that response through SLI.Lisp as predicate evidence, commit product output only after SLI.Lisp tick completion, and keep model binding, provider calls, authority, action, GEL admission, SelfGEL mutation, heartbeat, CME.Actual, and Sanctuary.Actual closed.

The adapter in this bench is not a provider integration. It is a deterministic harness used to verify the tool body's tick membranes before any live LLM binding is considered.
