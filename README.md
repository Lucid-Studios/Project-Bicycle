# Project Bicycle

Project Bicycle is the standalone public test payload for Project Sanctuary.

It packages the current runnable harness in a small repository so outside labs
can test the governed tool-use concept without cloning the archive body.

## Relationship To Project Sanctuary

Project Sanctuary is the public release and protocol home:

<https://github.com/Lucid-Studios/Project-Sanctuary>

Project Bicycle is the first ride package. It contains the code body and lab
protocol needed to run cold build and test checks in a bounded review posture.

Codex Mirror remains archive lineage only. It is not required for this package.

## Download

Clone the standalone package:

```powershell
git clone https://github.com/Lucid-Studios/Project-Bicycle.git
cd Project-Bicycle
```

Or download the release zip from the GitHub Releases page.

## First Ride

Run the direct cold test path:

```powershell
dotnet test ".\OAN Mortalis V1.2.1\San.sln"
```

Then run the operator-facing wrapper path:

```powershell
.\build.ps1 -Configuration Release
.\test.ps1 -Configuration Release -NoBuild
```

If a command fails, record the exact command, environment, error summary, and
whether any boundary claim was affected. Do not treat a build failure as a
theory failure without further review.
