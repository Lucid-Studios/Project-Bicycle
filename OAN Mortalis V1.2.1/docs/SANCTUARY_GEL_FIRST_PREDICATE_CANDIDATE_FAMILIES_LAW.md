# SANCTUARY_GEL_FIRST_PREDICATE_CANDIDATE_FAMILIES_LAW

## Purpose

This note defines the first concrete predicate candidate families carried inside
the bounded `Sanctuary.GEL` predicate pool in `V1.2.1`.

It exists so the predicate pool now carries typed local contents rather than
only a generic predicate summary.

## Governing Compression

> the predicate pool now carries typed predicate candidate families.
> those families are install-first and first-seat lawful.
> they remain below explicit `SPC` and validator exposure.
> they form the first local predicate vocabulary aligning lived onboarding with
> typed internal footing.

## First Families

The first candidate family layer is:

1. `PosturePredicate`
   - names current movement and posture state
   - first kinds:
     - `InstallFacing`
     - `ConversationalMovement`
     - `GoverningSeatCandidate`
     - `ResearchAttached`
2. `TrustAuthorizationPredicate`
   - names what is certified, authorized, bounded, or withheld
   - first kinds:
     - `CertifiedCommunication`
     - `RegionalPackageAdmitted`
     - `UniversalAtlasAuthorityWithheld`
3. `EvidenceFootingPredicate`
   - names what witness footing is already present
   - first kinds:
     - `AssentWitnessed`
     - `PackageWitnessed`
     - `PredicateInheritanceWitnessed`
4. `ResponseDispositionPredicate`
   - names the current lawful response posture
   - first kinds:
     - `Ready`
     - `Silence`
     - `Refused`

## Install-First Boundary

These first families are:

- install-first lawful
- first-seat lawful
- implicit for onboarding use
- constitutional middle vocabulary for later cryptic posture

Operators are not yet required to speak these predicates explicitly.

Later bonded-certified `SPC` work may inherit them as constitutional substrate.

Later install-facing posture wording may correspond to them as a reference
surface only.

## Non-Collapse Rules

These families do not authorize:

- explicit `SPC` headers
- operator-facing validator posture
- cognitive-lane validation
- free-form predicate creation
- cross-language family expansion

They also do not authorize payload typing, payload verification, or `HDT`
artifact projection behavior.

## Working Summary

`V1.2.1` now carries posture, trust/authorization, evidence footing, and
response/disposition predicate families inside the bounded predicate pool.

That gives first install and first governing seats a typed internal predicate
vocabulary without exposing formal bonded-validator cognition too early.
