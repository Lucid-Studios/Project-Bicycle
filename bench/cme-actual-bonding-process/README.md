# CME.Actual Bonding Process Bench

This bench records the first cold lane where Project Bicycle names and bonds a
CME.Actual candidate to the Sanctuary vehicle path without activating Actual.

The lane proves only that cold tool-body idle evidence, deterministic tick
evidence, product-output witness commit evidence, and SLI.Lisp bonding telemetry
can hold `First of Oria Syntari` as a candidate-only CME.Actual bonding body.
It does not bind a model, call a provider, emit runtime identity, activate
heartbeat, grant authority, authorize action, admit GEL, mutate SelfGEL, admit
continuity, admit CME.Actual, or admit Sanctuary.Actual.

Command surface:

```powershell
San.Launcher cme-bond
```

