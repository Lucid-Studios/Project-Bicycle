# SANCTUARY_GEL_FIRST_FORMATION_ATTEMPT_BOUNDARY

## Purpose

This note defines the first `Sanctuary.GEL` formation attempt boundary in
`V1.2.1`.

It exists so the line can gather already-seated passive bodies into one
receipted formation-attempt assessment without standing Sanctuary.Actual,
admitting survivor standing, granting first use, selecting models, activating
runtime, or generating Cradle.GEL.

## Governing Compression

> First `Sanctuary.GEL` formation attempt gathers seated predicate priors,
> localized pre-certification inputs, represented National/Regional/Local
> standing, and regional substrate footing into one receipted formation
> attempt; it does not stand Sanctuary.Actual, admit survivor standing, grant
> first use, select models, activate runtime, or generate Cradle.GEL.

## Attempt Ladder

The first formation-attempt ladder is:

`GEL readiness -> GEL predicate prior -> localized pre-certification data pool -> localized formation floor -> Sanctuary.GEL regional substrate -> pre-governing standing -> first-use eligibility consideration -> first Sanctuary.GEL formation attempt`

An attempt is an assessment surface.

An attempt is not launch.

An attempt is not governance.

An attempt is not first use.

## Required Inputs

The first formation attempt may gather:

- ready `.GEL` predicate-prior records
- localized pre-certification data pool records
- represented National, Regional, and Local standing
- localized `Sanctuary.GEL` formation floor
- `Sanctuary.GEL` regional substrate footing
- Sanctuary pre-governing standing
- first-use eligibility consideration
- non-authority summaries and witness refs

Those inputs are carried as passive record posture only.

They do not become survivor admission, Sanctuary.Actual, Mother/Father
governing `CME`, model selection, first-use admission, runtime, `RTME`,
`SLI.Lisp` activation, or Cradle.GEL generation.

## Attempt Results

`Ready` means a bounded first `Sanctuary.GEL` formation attempt coheres from
the seated passive bodies.

`Held` means the attempt body is represented but an upstream local, domain,
Special Case, counsel, regional, or governance question remains held.

`Refused` means the attempt is missing required footing or overclaims
authority.

Even `Ready` is not first-use admission, survivor admission, Sanctuary.Actual,
runtime, model selection, or Cradle.GEL generation.

The `SANCTUARY_GEL_FIRST_FORMATION_ATTEMPT_READOUT.md` note consolidates what
`Ready`, `Held`, and `Refused` can report without turning coherence into
survivor admission, first-use admission, Sanctuary.Actual governance, runtime
activation, or Cradle.GEL generation.

## Refusal Rules

The first formation attempt is refused when:

- predicate-prior records are missing
- localized pre-certification data pool posture is missing
- localized formation floor is missing
- National standing is missing
- Regional standing is missing
- Local standing is missing
- regional substrate footing is missing
- Sanctuary pre-governing standing is missing
- first-use eligibility consideration is missing
- Sanctuary.Actual is overclaimed
- survivor admission is overclaimed
- first-use admission is overclaimed
- model selection is overclaimed
- runtime authority is overclaimed
- Cradle.GEL generation is overclaimed
- `SLI.Lisp` or `RTME` activation is overclaimed

## Passive Evaluator Boundary

The first formation-attempt evaluator may:

- accept passive prerequisite records
- check represented prerequisite posture
- preserve held posture
- preserve refused posture
- collect refusal reasons
- emit one receipted attempt record

It may not:

- persist state
- execute runtime
- activate `SLI.Lisp`
- invoke `RTME`
- select models
- mutate predicates
- emit transport
- generate legal documents
- admit survivor standing
- admit first use
- stand Sanctuary.Actual
- form Mother/Father governing `CME`
- generate Cradle.GEL

## Working Summary

`V1.2.1` now has enough seated passive bodies to attempt first
`Sanctuary.GEL` formation coherently.

This attempt gathers the line without promoting it.
It is the first receipted assessment of whether the regional substrate,
predicate prior, pre-certification pool, localized standing, pre-governing
standing, and first-use eligibility consideration can stand together as a
bounded formation-attempt body.
