# LOCALIZED_PRE_CERTIFICATION_DATA_POOL_BOUNDARY

## Purpose

This note defines the localized pre-certification data pool boundary in
`V1.2.1`.

It exists so represented source, template, and standing inputs can contextualize
localized `Sanctuary.GEL` formation without becoming active law, consent,
certification, domain authority, first-use admission, `RTME`, governance, or
runtime.

## Governing Compression

> Pre-certification data pool formation may contextualize `Sanctuary.GEL`, but
> it does not certify, disclose, consent, authorize, govern, or activate
> runtime.

## Localized Pool Ladder

The localized pre-certification data-pool ladder is:

`represented source/template/standing inputs -> localized pre-certification data pool -> localized Sanctuary.GEL formation -> Sanctuary pre-governing standing -> first-use eligibility consideration`

The pool is upstream of localized `Sanctuary.GEL` formation.

The pool is not the formed `.GEL`.

The pool is not first-use eligibility consideration.

## Allowed Representation

The localized pre-certification data pool may reference, stage, and localize:

- Lab asset candidate refs
- RootAtlas regional source posture refs
- legal-admin template-family refs
- National standing refs
- Regional standing refs
- Local standing refs
- data-rights posture
- research-separation posture
- Special Case hold
- domain hold
- non-authority summaries

These are represented inputs only.

They do not become active legal documents, active RootAtlas authority, consent
records, disclosure surfaces, certification claims, or runtime instructions.

## Explicit Non-Powers

This pool does not activate:

- certification
- counsel-approved terms
- consent records
- disclosure issuance
- domain authorization
- first-use admission
- `RTME`
- governing `CME`
- runtime authority
- Atlas mutation
- legal template bodies

## Refusal Rules

Localized pre-certification data pool formation is refused when:

- National standing is missing
- Regional standing is missing
- Local standing is missing
- active legal terms are overclaimed
- certification is overclaimed
- consent records are overclaimed
- disclosure issuance is overclaimed
- domain authorization is overclaimed
- first-use admission is overclaimed
- `RTME` is overclaimed
- governing `CME` is overclaimed
- runtime authority is overclaimed

## Working Summary

`V1.2.1` now names a localized pre-certification data pool upstream of
localized `Sanctuary.GEL` formation.

The pool lets Build carry represented Lab asset, RootAtlas regional posture,
legal-admin template-family, standing, data-rights, research-separation,
Special Case, domain-hold, and non-authority inputs without laundering those
inputs into active law, consent, certification, authorization, governance,
first use, `RTME`, or runtime.
