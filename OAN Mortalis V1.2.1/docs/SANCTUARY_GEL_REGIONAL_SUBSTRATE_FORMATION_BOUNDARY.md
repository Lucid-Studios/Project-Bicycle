# SANCTUARY_GEL_REGIONAL_SUBSTRATE_FORMATION_BOUNDARY

## Purpose

This note defines the `Sanctuary.GEL` regional substrate formation boundary in
`V1.2.1`.

It exists to distinguish the specific regional/root `Sanctuary.GEL` substrate
from the broader `GEL = Generative Engrammitization Library`, from localized
formation posture, from Sanctuary.Actual Mother/Father governing `CME`, and
from later Cradle.GEL generation.

## Governing Compression

> `Sanctuary.GEL` regional substrate formation records the bounded regional
> GEL body required before Sanctuary.Actual governing CME and later Cradle.GEL
> generation may be considered; it does not stand Sanctuary.Actual, select
> models, authorize governance, activate runtime, or generate Cradle.GEL.

## Substrate Hierarchy

The current hierarchy is:

```text
Sanctuary Body
= the full program body

Sanctuary.GEL
= regional/root local GEL substrate for Sanctuary

Sanctuary.Actual Mother/Father governing CME
= later governing formation that requires Sanctuary.GEL substrate

Cradle.GEL
= later CradleTek-local GEL generated downstream from standing Sanctuary governance
```

The regional substrate ladder is:

`GEL predicate-prior formalization -> localized pre-certification data pool -> Sanctuary.GEL regional substrate formation -> Sanctuary pre-governing standing -> first-use eligibility consideration -> later Sanctuary.Actual Mother/Father governing CME -> later Cradle.GEL generation`

## Formation Meaning

`Sanctuary.GEL` regional substrate formation is the formation of the
regional/root local GEL body for Sanctuary.

It is not the whole Sanctuary Body.

It is not Sanctuary.Actual.

It is not Mother/Father governing `CME`.

It is not model selection.

It is not Cradle.GEL generation.

The localized `Sanctuary.GEL` formation boundary remains the constitutional
floor. It says the substrate may form only under represented National,
Regional, and Local standing.

This boundary names the specific body that is forming inside that floor:
`Sanctuary.GEL` as regional/root substrate.

## Required Inputs

Regional substrate formation may reference:

- ready `.GEL` predicate-prior refs
- bounded predicate pool refs
- first four predicate-family refs
- localized pre-certification data pool refs
- National standing refs
- Regional standing refs
- Local standing refs
- data-rights posture
- research-separation posture
- Special Case hold
- domain hold
- regional package footing
- candidate-only admission ceiling
- non-authority summaries

These are formation inputs and witness refs only.

They do not become Sanctuary.Actual, Mother/Father governing `CME`, model
selection, Cradle.GEL, runtime authority, domain authority, or final survivor
admission.

## Downstream Rule

Sanctuary.Actual Mother/Father governing `CME` may not be approached as a
standing body until `Sanctuary.GEL` regional substrate formation is represented.

Cradle.GEL generation may not be approached until later standing Sanctuary
governance exists.

Cradle.GEL must not be generated directly from install materials, raw `.GEL`
readiness, predicate-prior formalization, or localized pre-certification data
pool posture.

## Explicit Non-Powers

`Sanctuary.GEL` regional substrate formation does not:

- stand Sanctuary.Actual
- stand Mother/Father governing `CME`
- select models
- authorize governance
- activate runtime
- generate Cradle.GEL
- admit final survivor standing
- grant first use
- authorize domain action
- activate `RTME`
- activate `SLI.Lisp`
- authorize EC mutation
- emit transport
- certify
- mint consent
- issue counsel-reviewed disclosure

## Refusal Rules

Regional substrate formation is refused when:

- predicate-prior refs are missing
- localized pre-certification data pool refs are missing
- National standing is missing
- Regional standing is missing
- Local standing is missing
- regional package footing is missing
- candidate-only admission ceiling is missing or widened
- Sanctuary.Actual is overclaimed
- Mother/Father governing `CME` is overclaimed
- model selection is overclaimed
- Cradle.GEL generation is overclaimed
- governance or runtime authority is overclaimed

formation line: `Sanctuary.GEL` regional substrate.

`GEL prior -> Sanctuary.GEL regional substrate -> later Sanctuary.Actual governance -> later Cradle.GEL generation`

Mother/Father governing `CME` work without standing that governance early.
