# SANCTUARY_GEL_PREDICATE_POOL_LAW

## Purpose

This note defines the first bounded `.GEL` predicate pool in `V1.2.1`.

It exists so first `Sanctuary.GEL` formation receives one explicit predicate-
bearing local body between the formation data pool and the first retained local
substrate.

## Governing Compression

> the predicate pool is downstream of `SanctuaryGelFormationDataPool` and
> upstream of first `Sanctuary.GEL`.
> it carries bounded lab predicate inheritance into local `.GEL` footing
> without becoming not raw Atlas authority, a universal Atlas replica, or
> exposed bonded-validator posture.
> first install and first governing seats may inherit this bounded predicate
> body before later bonded-certified `SPC` activation is lawful to expose.

## Three Layers

The current sequence is:

1. install / first-seat layer
   - lived posture
   - bounded predicate pool
   - first governing-seat footing
2. implicit typed layer
   - internal predicate structure
   - candidate tracking
   - receipt-bearing internal evaluation
3. later bonded-certified layer
   - exposed `SPC`
   - explicit validator
   - receipt discipline surfaced for formal bonded work

`Gnome Speak NLP²` and conversational movement belong to the install-first
lived layer.

`SPC` belongs to later formal bonded-cognition activation.

The predicate pool is the bridge between those layers inside `.GEL`.

The first concrete family layer beneath that bridge is:

- posture
- trust / authorization
- evidence footing
- response / disposition

In compressed form: posture trust / authorization evidence footing response / disposition.

An install-facing correspondence layer may later reference these families as
bounded posture wording, but that correspondence layer remains downstream and
reference-only.

## Predicate Pool Office

The first `.GEL` predicate pool is:

- one bounded local predicate body
- derived from the formation data pool
- English-language-package relative in this phase
- sufficient for first local `.GEL` symbolic footing and future cryptic
  inheritance

It is not:

- a full universal Atlas replica
- a runtime reasoning validator
- public-facing doctrine output
- exposed bonded-certified cognition machinery

## First Ontology

The first predicate pool should carry at minimum:

- pool identity / handle
- predicate lineage summary
- active language / locale / jurisdiction
- admitted regional package identity
- predicate inheritance witness
- predicate candidate set summary
- posture summary for first governing seats
- optional site-binding and use-posture references
- typed predicate candidate families and family-bearing candidate kinds

In the current phase this footing remains English-only.

## Conservative Boundaries

The first predicate pool may not:

- promote predicates
- mutate Atlas authority
- multiplex across language groups
- expose explicit operator-facing validator grammar
- activate bonded `SPC`

First install may carry these families implicitly while remaining
conversational on the surface.

That conversational surface is not payload shaping, artifact projection, or
runtime authority.

## Disposition Grammar

The predicate pool stands in one of three postures:

- `Ready`
- `Silence`
- `Refused`

`Ready` means:

- the upstream formation data pool is ready
- bounded local predicate footing is present

`Silence` means:

- the upstream formation pool remained silent
- the predicate pool must preserve that silent security posture

`Refused` means:

- the upstream body was recognized but not ready to yield bounded predicate
  footing

## Non-Collapse Rules

The predicate pool is:

- downstream of the formation data pool
- upstream of first `.GEL`
- install-first bounded local predicate footing

It is not:

- raw `RootAtlas`
- universal Atlas family authority
- explicit bonded-validator posture
- formal `SPC` activation

In other words, it is not explicit bonded-validator posture in this phase.

## Working Summary

`V1.2.1` now names a bounded predicate pool between the formation data pool and
first local `.GEL`.

That pool preserves English-only regional footing, bounded predicate
inheritance, and first governing-seat posture while keeping explicit `SPC` and
validator exposure withheld until later bonded-certified work.

Any install-facing posture wording seated later remains correspondence only and
must not impersonate `HDT` artifact law, Sanctuary law, or admissibility law.
