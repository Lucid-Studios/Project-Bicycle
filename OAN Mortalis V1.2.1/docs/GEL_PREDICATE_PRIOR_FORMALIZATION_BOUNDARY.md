# GEL_PREDICATE_PRIOR_FORMALIZATION_BOUNDARY

## Purpose

This note defines the first `.GEL` predicate-prior formalization boundary in
`V1.2.1`.

It exists so `GEL = Generative Engrammitization Library` can carry a structured
predicate-prior object without treating that object as final
`Sanctuary.GEL` survivor admission, first use, `SLI.Lisp` activation, EC
mutation, or runtime authority.

## Governing Compression

> `.GEL` predicate-prior formalization records a rooted, witnessed,
> SLI-constructor-bearing, Engrammitization-facing candidate as a bounded
> library prior; it does not admit final `Sanctuary.GEL` survivor standing,
> grant first use, authorize EC mutation, activate `SLI.Lisp`, or create
> runtime authority.

## Formalization Ladder

The predicate-prior formalization ladder is:

`raw data -> UTF-8 witness -> RootAtlas root predicate -> SLI symbolic constructor -> .GEL predicate prior -> Engrammitization carrier review -> later SLI.Lisp mutation / transport / EC operations -> later Sanctuary.GEL survivor admission if warranted`

This boundary sits downstream of `GEL` formation readiness and upstream of
localized `Sanctuary.GEL` formation.

Formalization is not localized formation.

Formalization is not survivor admission.

Formalization is not first-use permission.

## Predicate Object

The build-facing predicate object is layered:

```text
predicate_object:
  witness
  root
  constructor
  gel_prior
  invariants
  mutation_policy
  transport_receipts
  admission_ceiling: candidate_only
```

The object is a predicate prior, not a public artifact, active legal object,
consent record, runtime command, or admitted survivor body.

## UTF-8 Witness Rule

UTF-8 is the first lawful witness field.

It must preserve source text, encoding state, token or span bounds, local
context, source witness, ambiguity, and Unicode snapshot posture before
symbolic assignment.

Symbolics may compress and deepen the object, but they may not replace the
witness.

## Root Predicate Rule

RootAtlas grounding gives root predicate identity.

It does not create local RootAtlas authority, Atlas mutation, domain authority,
or universal source sovereignty.

Root predicate references remain lineage-bearing and traceable.

## SLI Constructor Rule

The `SLI` symbolic constructor is attachment-native and structured.

It must be carried as:

- `prefix.super`
- `prefix.sub`
- `body`
- `suffix.super`
- `suffix.sub`

A flat rendering is only a lossy debug or display compromise.

`SLI.Lisp` may later operate on these structured constructor fields, not on a
flat rendering as canonical authority.

## Predicate Prior Rule

`.GEL` stores predicate priors.

It does not store final survivor admission.

A predicate prior may carry:

- rooted witness posture
- root predicate posture
- SLI constructor posture
- Engrammitization-facing posture
- invariant summaries
- mutation-policy posture
- transport-receipt posture
- unresolved ambiguity
- hold, refusal, or fork posture
- candidate-only admission ceiling

## Mutation And Transport Boundary

EC mutation and transport are future-facing from this boundary.

If later transformation preserves the root body and declared invariants, it may
be considered for lawful mutation or transport by later law.

If later transformation changes the body without admission, it must be treated
as a fork, hold, or refusal by later law.

This boundary does not perform mutation, transport, EC operations, `SLI.Lisp`
execution, or admission.

## Explicit Non-Powers

Predicate-prior formalization does not:

- admit final `Sanctuary.GEL` survivor standing
- grant localized `Sanctuary.GEL` formation by itself
- grant Sanctuary pre-governing standing
- grant first-use eligibility or first-use admission
- authorize EC mutation
- activate `SLI.Lisp`
- emit transport
- create runtime authority
- govern
- certify
- authorize domains
- mint consent
- issue counsel-reviewed disclosure
- mutate Atlas authority
- promote predicates
- expose `SPC` validator posture

## Refusal Rules

Predicate-prior formalization is refused when:

- UTF-8 witness posture is missing
- RootAtlas root predicate posture is missing
- SLI symbolic constructor posture is missing
- Engrammitization-facing posture is missing
- predicate-surface readiness is missing
- survivor admission is overclaimed
- first use is overclaimed
- EC mutation or transport is overclaimed
- `SLI.Lisp` activation is overclaimed
- runtime or governance authority is overclaimed

## Working Summary

`V1.2.1` now gives `.GEL` a predicate-prior formalization body.

The predicate prior is formal enough to be carried, reviewed, and later
approached by structured `SLI.Lisp` and EC work, but it remains bounded by a
candidate-only admission ceiling and cannot become survivor admission,
first-use permission, mutation authority, transport authority, governance,
`RTME`, or runtime.
